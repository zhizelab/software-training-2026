# 软件组后续学习计划与研究方向说明

现在开始实验室软件组的学习任务布置与兴趣意向收集。大家在力所能及的范围内可以学习多个方向，但至少选择一个方向：

## 1. 强化学习方向

目前强化学习方向的任务已经讨论完毕，暂定方向是基于强化学习实现四足机器狗的运控与导航。选这个方向的同学现在就可以开始收集资料与学习了，请从任务清单（见 [《四足机器人强化学习研究方向目录与概述》](./quadruped_rl_research_directions_formatted.pdf)）中选择一个感兴趣的二级研究专题（或自选类似的强化学习方向），搜集最新的学术论文和开源代码库，阶段性目标是在自己理解的基础上形成一篇综述论文。

## 2. 其他软件相关方向

对强化学习不感兴趣、但仍然想做软件相关的同学，目前仅做学习兴趣调研，可以考虑以下几个方向：

- 基于实验室已有本体（麦轮车、GO1 EDU、SO-101 主从机械臂、自组装的四足机器狗）自行拟定一个感兴趣的研究方向
- Agent 开发
- 嵌入式软件开发（基于 STM32、ESP32 等）
- 传统运控以及 ROS 系统相关的开发（基于已有本体）
- 网页与网络维护（需要 2-3 名同学维护机房服务器、实验室网站）
